# انتشار «سیمرغ» در کافه‌بازار و مایکت

با انتشار در این فروشگاه‌ها، دیگر هیچ هشدارِ Google Play Protect («برنامه مسدود شد / این توسعه‌دهنده را ندیده‌ام») به کاربران نشان داده نمی‌شود، چون کاربر برنامه را از خودِ فروشگاه نصب می‌کند.

## آنچه در این پوشه آماده است

| فایل | کاربرد |
|------|--------|
| `icon-512.png` | آیکونِ برنامه ۵۱۲×۵۱۲ (برای صفحه‌ی فروشگاه) |
| `feature-graphic.png` | کاور/بنرِ بالای صفحه (۱۰۲۴×۵۰۰) |
| `screenshots/01-calendar.png` … | اسکرین‌شات‌های برنامه (شمسی، روز، اوقات شرعی، تیره) |
| `description-fa.txt` | عنوان، توضیحاتِ کوتاه و کاملِ آماده برای کپی‌کردن |

## فایلِ نصبی (APK) برای آپلود

از آخرین بیلدِ موفق روی شاخه‌ی `main` بگیرید:
- صفحه‌ی Actions پروژه → آخرین «Build Android APK» → بخشِ **Artifacts** → `simorgh-ledger` → دانلودِ ZIP → داخلش `simorgh-ledger.apk`.

این APK با کلیدِ ثابتِ release امضا شده (`android/app/simorgh-release.keystore`) و برای فروشگاه آماده است.

> نکته‌ی مهم برای آپدیت‌های بعدی: قبل از هر انتشارِ جدید، در `android/app/build.gradle` مقدارِ `versionCode` باید **یک واحد زیاد** شود (نسخه‌ی فعلی: ۲۸) وگرنه فروشگاه آپلود را رد می‌کند.

## الف) کافه‌بازار

۱. به **پیشخوانِ توسعه‌دهنده** بروید: https://pishkhan.cafebazaar.ir (ورود با حسابِ کاربری؛ ثبت‌نامِ توسعه‌دهنده رایگان است؛ یک‌بار احرازِ هویت لازم است).
۲. **«افزودنِ برنامه‌ی جدید»** → بسته‌ی `simorgh-ledger.apk` را آپلود کنید (شناسه‌ی بسته: `com.simorgh.ledger`).
۳. اطلاعاتِ صفحه را پر کنید (از `description-fa.txt` کپی کنید):
   - نامِ برنامه، توضیحِ کوتاه، توضیحِ کامل
   - دسته‌بندی: «مالی و کسب‌وکار» یا «ابزارها»
   - آیکون: `icon-512.png`
   - تصویرِ کاور: `feature-graphic.png`
   - اسکرین‌شات‌ها: فایل‌های پوشه‌ی `screenshots/` (حداقل ۳ تا)
۴. **دسترسی‌ها**: برنامه فقط از اینترنت و یادآوری/نوتیفیکیشن استفاده می‌کند؛ توضیحِ خاصی لازم نیست.
۵. **رده‌بندیِ سنی** را «همه» و قیمت را «رایگان» بگذارید.
۶. **ارسال برای بررسی**. معمولاً ظرفِ ۱ تا ۳ روزِ کاری تأیید و منتشر می‌شود.

## ب) مایکت

۱. به **کنسولِ توسعه‌دهنده‌ی مایکت** بروید: https://web.myket.ir (یا developer.myket.ir) و وارد شوید.
۲. **«برنامه‌ی جدید»** → `simorgh-ledger.apk` را آپلود کنید.
۳. همان اطلاعاتِ بالا را پر کنید (عنوان، توضیحات، دسته، آیکون، کاور، اسکرین‌شات‌ها).
۴. ارسال برای بررسی؛ پس از تأیید منتشر می‌شود.

## بازتولیدِ تصاویر (اختیاری)

اگر بعداً ظاهر را تغییر دادید و خواستید تصاویرِ تازه بسازید:

```bash
npm run build
npm install --no-save puppeteer
npx vite preview --port 4173 &     # یک ترمینالِ جدا
node scripts/store-assets.mjs      # تصاویر در store/ ساخته می‌شوند
```
