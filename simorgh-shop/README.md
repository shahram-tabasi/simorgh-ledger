# صندوقِ فروشگاهیِ سیمرغ (simorgh-shop)

POS سبک و آفلاین برای مغازه‌ها — مثلِ **محک/هلو** اما ساده، رایگان و روی سیستمِ خودِ مغازه.
بدونِ نیاز به اسکنرِ سخت‌افزاریِ گران: **گوشیِ هوشمند را با همان آپ به اسکنرِ بی‌سیمِ لپ‌تاپ تبدیل کنید.**

## امکانات
- **فروش (صندوق):** اسکنِ بارکد → سبدِ خرید → فاکتورِ چاپی. اسکن از سه راه: اسکنرِ سخت‌افزاریِ صفحه‌کلیدی، **دوربینِ همین دستگاه**، یا **اسکنرِ بی‌سیمِ گوشی**.
- **کالاها:** افزودن/ویرایش، تولیدِ خودکارِ بارکد و **چاپِ لیبلِ بارکد** (Code39).
- **گزارش:** فروش و سودِ امروز، تعدادِ فاکتور، ارزشِ موجودی، هشدارِ کم‌موجود.
- **کاملاً آفلاین:** داده‌ها در مرورگرِ همان دستگاه (localStorage) ذخیره می‌شوند.

## اسکنرِ بی‌سیمِ گوشی (به‌جای دستگاهِ گران)
۱. روی لپ‌تاپ: `npm run build` و سپس `npm run serve` → آدرسی مثلِ `http://192.168.1.20:8090` می‌دهد.
۲. روی صندوقِ فروش دکمه‌ی **«📡 اسکنرِ همراه»** را بزنید؛ یک کدِ ۶رقمی نشان می‌دهد.
۳. روی گوشیِ هم‌شبکه، همان آدرسِ لپ‌تاپ را با `/?scan` باز کنید، کد را وارد کنید و شروع به اسکن کنید.
۴. هر بارکدی که گوشی بخواند، **روی صندوقِ لپ‌تاپ به سبد اضافه می‌شود.**

## اجرا
```bash
npm install
npm run dev        # توسعه
# یا برای فروشگاه:
npm run build
npm run serve      # سرور + اسکنرِ بی‌سیم روی پورتِ 8090
```

> این پروژه از قطعاتِ آزموده‌ی **simorgh-ledger** (بارکدِ Code39، اسکنرِ ZXing، رله‌ی بی‌سیم) ساخته شده است.
